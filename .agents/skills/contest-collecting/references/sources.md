# 출처 사이트별 수집 가이드

검증된 현황(2026-06 기준). 사이트 구조는 바뀔 수 있으니 수집 전 진입 페이지를 한 번 확인한다.

## wevity (www.wevity.com) — 1순위 권장
- robots.txt: `Allow: /` (전면 허용, GPTBot만 crawl-delay 3).
- 목록은 **서버 렌더링 HTML** → requests+BeautifulSoup로 수집 가능.
- 필터: 분야 / **대상**(제한없음·일반인·대학생·청소년·어린이) / 주최기관 / 시상규모 / 상태(접수중·마감임박·마감·신규).
- 수집 대상: 대상=**어린이·청소년**. URL 파라미터 형태 예: `?c=find&s=1&gub=1&cidx=...` (대상/분야 파라미터를 조합).
- 한계: 대상이 어린이/청소년까지만 — **초/중/고 세분화는 안 됨** → normalizer가 참가자격 원문으로 재분류해야 함.

## contestkorea (www.contestkorea.com)
- robots.txt: `Allow: /` (전면 허용).
- 공모전 목록 + 대상/분야 필터 제공. 상세 페이지에 참가자격·일정 원문 존재.

## all-con (www.all-con.co.kr)
- robots.txt 확인 시 SSL 인증서 경고가 날 수 있음 → 수집 전 접속 가능성·약관을 먼저 확인.
- 공모전·대외활동·봉사 등 카테고리 보유.

## thinkcontest (www.thinkcontest.com / thinkgood)
- 청소년·학생 대상 공모전 비중이 높아 우리 타깃과 적합도 높음.
- 진입: `/thinkgood/index.do`. 상세 일정·대상 확인.

## 저작권 안전 출처 (권장 보강)
아래는 1차 출처(주최측)라 저작권 위험이 낮고 신뢰도가 높다. 가능하면 함께 수집한다.
- 시·도 교육청 공지/공모 게시판
- 한국과학창의재단 등 공공기관 공모
- 기업 CSR/재단 공모전 공식 페이지

## 공통 예절
- 요청 간 1~3초 간격, 명시적 User-Agent, 야간 대량 요청 자제.
- `source_url`은 항상 상세 페이지의 **고유 URL**로 저장(검수 시 재방문용).
